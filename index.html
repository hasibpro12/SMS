📞 পেমেন্ট নম্বর সেট করুন

📲 SMS রিডার অ্যাপ কানেক্ট

যে ফোনে পেমেন্টের SIM থাকবে, সেই ফোনে Android SMS রিডার অ্যাপ ইনস্টল করে নিচের তথ্য দিয়ে কানেক্ট করুন।

অ্যাপে উপরের URL ও Key দিয়ে কানেক্ট বাটন চাপুন। কানেক্ট সফল হলে ড্যাশবোর্ডে স্ট্যাটাস Online দেখাবে এবং SMS আসা মাত্র ট্রানজেকশন আপডেট হবে।

🧪 টেস্ট ট্রানজেকশন যোগ করুন (ডেমো)

❓ কিভাবে কাজ করে

  1. Firebase প্রজেক্ট তৈরি করুন এবং Realtime Database চালু করুন।
  2. সেটিংস ট্যাবে Database URL ও নম্বর সেট করে কী জেনারেট করুন।
  3. যে ফোনে পেমেন্টের SIM আছে, সেখানে Android SMS রিডার অ্যাপ চালু করুন।
  4. অ্যাপে Database URL + API Key দিয়ে কানেক্ট করুন।
  5. ড্যাশবোর্ডে অটো পেমেন্ট টগল চালু করুন।
  6. bKash/Nagad/Rocket থেকে টাকা এলে SMS পড়ে অ্যাপ ডাটাবেজে পাঠাবে → ড্যাশবোর্ডে দেখাবে।

⚠️ গুরুত্বপূর্ণ সতর্কতা

  • শুধুমাত্র নিজের মার্চেন্ট/ব্যবসায়িক নম্বরে ব্যবহার করুন।
  • API কী গোপন রাখুন।
  • Firebase Security Rules ঠিকভাবে সেট করুন যাতে শুধু আপনার কী দিয়ে লিখা যায়।
  • SMS পারমিশন শুধু প্রয়োজনীয় অ্যাপে দিন।
  • এই সিস্টেম অফিসিয়াল bKash/Nagad API নয় — SMS ভিত্তিক।
